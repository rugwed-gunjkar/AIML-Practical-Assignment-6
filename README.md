## Objective
To perform basic data preprocessing using Python and the UCI Adult Income Dataset.

## Tools and Technologies

- Pandas
- NumPy
- Scikit-learn
- VS Code

## Dataset
UCI Adult Income Dataset.

## Operations Performed
1. Loaded the dataset using Pandas.
2. Identified missing values.
3. Handled missing numerical values using median.
4. Handled missing categorical values using mode.
5. Encoded categorical variables using One-Hot Encoding.
6. Encoded the income column using Label Encoding.
7. Normalized numerical features using Min-Max Scaling.
8. Saved the processed dataset as adult_income_processed.csv.

The preprocessed dataset was successfully saved as a CSV file.
